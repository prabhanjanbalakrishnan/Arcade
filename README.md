# Side Quest Arcade

Small browser games, hosted free on GitHub Pages.

## Adding a game

1. Make a new folder named after the game, with the game saved as `index.html` inside it.
2. In the top-level `index.html`, copy the `<a class="cabinet">` block and change the link, name and description.
3. Commit and push. The site updates within a minute or so.

## Playing locally

Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8765
```
